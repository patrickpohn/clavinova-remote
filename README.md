# Clavinova Remote

Web-App zum Steuern eines Yamaha Clavinova CLP-825 vom Handy aus (Web MIDI).

Öffnen in Chrome auf Android, Klavier per USB-Kabel (USB TO HOST, Typ B + OTG-Adapter) oder Bluetooth MIDI verbinden, dann „Mit Klavier verbinden“ tippen.

Neben den 10 Klängen des CLP-825 bietet die App über 50 weitere Instrumente (u. a. Harfe), die das Handy selbst erzeugt
(Samples: FluidR3 GM über gleitz/midi-js-soundfonts). Für Ton aus den Klavier-Lautsprechern das Handy per Bluetooth-Audio
mit „CLP-825 AUDIO“ koppeln.
